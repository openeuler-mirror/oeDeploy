# Introduction

oeDeploy is a lightweight software deployment tool designed to help developers rapidly and efficiently set up various software environments. It seamlessly adapts to both single-node and distributed scenarios.

- **Universal Scenario Support**: Fully supports a variety of environments, including single-node and cluster setups.
- **One-Click Deployment for Mainstream Software**: Features built-in standardized deployment solutions for common software. The development team will continually introduce new plugins for mainstream software to enhance oeDeploy's capabilities.
- **Flexible Plugin Management**: Offers an extensible architecture, empowering developers to create and integrate custom plugins tailored to their specific business requirements.
- **Efficient Development Experience**: Currently features a robust CLI, with a GUI tool on the roadmap. Developers can focus on workflow orchestration and core logic, achieving highly efficient software deployment with minimal code.
